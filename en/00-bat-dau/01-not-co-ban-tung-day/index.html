Lesson 1: Basic notes on each string

Core⏱ 60 minDraft

The names of the 6 strings, the first-position notes on each string, which left-hand finger presses which fret, and how to fret a clean note — the first step to playing guitar.

Goals

  • The student names the 6 strings correctly, from string 6 (low E) to string 1 (high E).
  • The student finds the natural notes (C D E F G A B / Đô Rê Mi Fa Sol La Si) in first position on each string.
  • The student knows which left-hand finger presses which fret and can fret a clean note with no buzz.
  • The student plays the C major scale in first position and a short melody.

Preparation

  • Teacher: close-up camera on the neck (frets 0–5 and all 4 left-hand fingers visible); a PDF of the note diagrams on this page.
  • Student: guitar in tune (see Lesson 3: Tuning); left-hand nails cut short; a metronome or phone app.

Main content

1. Fretting technique (left hand)

  • Left-hand finger numbers: 1 = index · 2 = middle · 3 = ring · 4 = little finger. The thumb has no number.
  • Thumb rests behind the neck, roughly in the middle, opposite finger 2. Don't squeeze.
  • Press with the fingertip, finger curved like an arch so it doesn't touch the next string.
  • Press right behind the fret wire (on the body side). Not in the middle of the space, not on top of the wire.
  • Just enough pressure: rest the finger lightly on the string, pluck, and press a little harder until the buzz stops. Stop there.
  • First-position rule: "one finger per fret". Fret 1 = finger 1, fret 2 = finger 2, fret 3 = finger 3, fret 4 = finger 4.
  • Fingers you aren't using stay close to the strings, ready to press. Don't lift them high.
  • "Press fret 3" = put the finger in the space between fret wire 2 and fret wire 3.

  • Memory aid: "Eddie Ate Dynamite, Good Bye Eddie" = E A D G B E (string 6 → string 1). In Vietnamese class: "Em Anh Đi Gặp Bạn Em".
  • Letters ↔ Đô-Rê-Mi: C = Đô · D = Rê · E = Mi · F = Fa · G = Sol · A = La · B = Si.
  • In the diagrams below, string 1 (e) is at the top and string 6 (E) at the bottom, the same as tab. The number in each dot = left-hand finger.

3. Notes on each string (first position)

String 6 — low E

  • Open = E · fret 1, finger 1 = F · fret 3, finger 3 = G.

String 5 — A

  • Open = A · fret 2, finger 2 = B · fret 3, finger 3 = C (low C, the root of the C chord).

String 4 — D

  • Open = D · fret 2, finger 2 = E · fret 3, finger 3 = F.

String 3 — G

  • Open = G · fret 2, finger 2 = A.
  • (Fret 4, finger 4 = B, the same note as open string 2. Beginners use the open B string, which is easier.)

String 2 — B

  • Open = B · fret 1, finger 1 = C (middle C) · fret 3, finger 3 = D.

String 1 — high E

  • Open = E · fret 1, finger 1 = F · fret 3, finger 3 = G.
  • Strings 1 and 6 have the same note names and the same fingers, two octaves apart.

5. Fretting exercises

  • Right hand: alternate i–m (index – middle) or use a pick. Play each note once, evenly.
  • The numbers under the tab = left-hand fingers (0 = open string, nothing pressed).

Exercise A — 1-2-3-4 (chromatic): one finger per fret. Do it on string 6, then 5, and so on down to string 1.

  • Going up: keep each finger down while you place the next one. Start at 50 bpm, 1 note per beat.

Exercise B — natural notes string by string: say each note name out loud as you play it.

  • B1 + B2 played together = all 17 natural notes from low E to high G. Then play them back down.

Exercise C — C major scale: C D E F G A B C (Đô Rê Mi Fa Sol La Si Đô).

6. Try it on the virtual guitar

  • Click a fret on the virtual neck to hear each note. Switch on "note names" or "Đô-Rê-Mi" labels to check yourself.

Lesson flow (60 minutes)

  • 5' — Hello, sound check, tune together with the teacher
  • 10' — Fretting technique: finger numbers, thumb, fingertip, close to the fret, just enough pressure
  • 5' — The 6 string names + the memory aid
  • 20' — Notes on each string, 6 → 1: the teacher points, the student frets and says the note name out loud
  • 15' — Exercises A, B, C slowly (50–60 bpm); try Exercise D if there is time
  • 5' — Summary, set the homework

Teaching online

  • A close-up camera on the left hand is a must: frets 0–5, fingertips and the thumb behind the neck must be clearly visible.
  • Webcam images are often mirrored. Always say string number – fret number – finger number, never "up/down" or "left/right".
  • The student says note names out loud while fretting, so the teacher can check even when video stutters or audio is compressed.
  • Call and response: the teacher plays 3–4 notes and stops completely, then the student plays them back. Don't play at the same time (network lag).
  • A slight buzz is hard to hear over Zoom/Meet. Ask the student to judge it, and check again in the video they send after the lesson.
  • Screen-share this page and use the cursor to point at the string being studied.

Common mistakes

  • Mixing up string numbers, e.g. calling the thinnest string "string 6". Remind them: string 1 = thinnest string, highest sound.
  • Confusing fret number and finger number on frets 2 and 3 (e.g. playing C on string 5 with finger 2).
  • Pressing with the pad of the finger, finger flat → it mutes the next string.
  • Pressing in the middle of the space or far from the fret wire → buzz; pressing on top of the wire → muted note.
  • Thumb squeezing hard or wrapping around the neck → tired hand, bent wrist.
  • Unused fingers lifted high, far from the strings → slow note changes.

Homework

  • 10–15 minutes a day, split into 2 sessions if the fingertips hurt.
  • Exercise A on all 6 strings, 50 bpm.
  • Exercises B1 + B2 up and down, saying the note names out loud.
  • Exercise C: C major scale up and down, 60 bpm.
  • Record a 30–60 second video of Exercise C or D with the left hand in view; send it via Zalo.

Completion checklist

  • Names the 6 strings (E A D G B E) without looking at the chart
  • Frets the right note when the teacher calls out "string – note" at random (e.g. "string 2, C")
  • Uses the correct finger according to "one finger per fret" in first position
  • Every fretted note sounds clean, no buzz, thumb relaxed
  • Plays the C major scale up and down at 60 bpm without stopping
