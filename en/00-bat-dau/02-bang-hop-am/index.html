How to read the notation

  • Each 6-character string reads from string 6 (low E) → string 1 (high E).
  • x = don't play that string · 0 = open string · number = fret to press.
  • When a fret is 10 or higher, separate with hyphens: x-10-12-12-12-10.
  • Left-hand finger numbers: 1 = index, 2 = middle, 3 = ring, 4 = little, – = no finger.
  • A chord can be played in many shapes; this chart gives only the most common shape for learners.
