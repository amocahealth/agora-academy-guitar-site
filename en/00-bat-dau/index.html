Start here: notes & chords

Two foundation pages for anyone picking up a guitar: the basic notes on each string (which finger presses which fret) and a common chord chart to look things up.

How to use this section

  • Lesson 1 — Basic notes on each string: study it first, even before Level 1. It covers the names of the 6 strings, the first-position notes, which left-hand finger presses which fret, and how to press for a clean sound.
  • Common chord chart: a reference page. Keep it open next to you whenever a lesson uses chords (Level 1 → Level 4).
  • The teacher screen-shares both pages in the very first session; students bookmark them for home practice.
  • To try things right away, tap 🎸 (bottom right) to open the virtual guitar and switch on "note names" or "Đô-Rê-Mi" labels.
