Lesson 5: p-i-m-a Arpeggios

Core⏱ 60 minDraft

Right-hand finger symbols p-i-m-a and basic arpeggio patterns on open-position chords.

Objectives

  • Students use the right-hand finger symbols correctly: p (thumb), i (index), m (middle), a (ring).
  • Play arpeggios in at least 4 patterns on C, Am, G, Em and D.
  • Keep the thumb on the right bass string for each chord.

Preparation

  • Teacher: PDF of the arpeggio patterns (in both tab and notation), backing track/metronome at 60 and 72 bpm.
  • Student: guitar, metronome, right-hand nails shaped as in lesson 4 (Accompaniment-track students may play with the fingertips).

Main content

  • "One finger per string" rule: p = bass strings (4–6), i = string 3, m = string 2, a = string 1.
  • Bass string by chord: C, Am → string 5; G, Em → string 6; D, Dm → string 4.
New chord: Dm (bass on string 4) — used in the C – Am – Dm – G loop
  • Pattern 1: p-i-m-a (ascending).
  • Pattern 2: p-a-m-i (descending).
  • Pattern 3: p-i-m-a-m-i (up – down, suits 3/4 or 6/8).
  • Pattern 4: p-i-m-i (4 notes, simple for children).
  • Pattern 5 (advanced): p + i-m-a together (block pluck).
  • Use tirando for i-m-a; let the strings ring, don't cut them off.
  • Classical reference: Giuliani "120 Arpeggios", Op. 1 (public domain) — pick the first 3–4 patterns.
  • Accompaniment use: slow arpeggios for the intro/first section of a ballad.

Lesson flow (60 minutes)

  • 5' — Warm-up, tuning
  • 10' — Review apoyando/tirando (Accompaniment students: review Level 1 chord changes)
  • 25' — p-i-m-a symbols, "one finger per string" hand placement, patterns 1 → 4 on C
  • 15' — Chord loop C – Am – Dm – G with patterns 1 and 3 (Dm is a new chord — introduce it briefly, bass on string 4)
  • 5' — Summary, assign homework

Online teaching notes

  • Right-hand close-up camera so you can see which finger plays which string; the left hand only needs the chord shape visible.
  • Ask beginners to say the finger names aloud ("p – i – m – a").
  • Arpeggios get distorted by noise suppression → turn on original sound.
  • Call-and-response one bar per pattern; never arpeggiate together with the student.
  • Pre-record a video of each pattern at 2 tempos for home practice.
  • Share the PDF with both tab and notation — Accompaniment students read the tab, Classical students read the notes.

Common mistakes

  • Thumb on the wrong bass string (e.g. string 6 for a C chord).
  • i-m-a "jumping" off the strings and resetting every time → losing the beat.
  • Uneven dynamics; the a finger is usually too quiet.
  • Lifting the left hand too early when changing chords → sound cuts out.

Homework

  • Patterns 1–4 on each of C, Am, G, Em, D (4 times per pattern).
  • Chord loop C – Am – Dm – G with pattern 3, 60 bpm.
  • Classical students: the first 3 patterns of Giuliani Op. 1.
  • Send a video of one chord loop.

Completion criteria

  • Plays all 4 arpeggio patterns on C, evenly at 60 bpm
  • Thumb finds the correct bass string for all 5 chords
  • Plays one 4-chord loop continuously without stopping
